# 手绘水彩故事视频：角色设定、音色选角与分镜提示词模板

本文档提供在使用 `watercolor-story-video` Skill 制作故事动画时的标准设定表与生图提示词拼接规范，旨在解决**跨镜头角色变脸、水彩画风漂移、画面出现乱码文字、景别单一**四大常见问题。

---

## 1. 角色视觉锚点设定表（Character Visual Bible）

在拆解分镜之前，必须先从故事文本中提取所有出场角色，并为每个角色编写**固定外观描述块（Visual Anchor Block）**。后续凡是有该角色出场的镜头，提示词中必须**原样复制**该描述块，不得随意增减服饰或改变配色。

### 角色设定表模板

| 角色 ID (`speaker`) | 角色名称 | 身份与性格 | 固定外观描述块（生图必带） | 明确禁止项（Negative Rules） | 字幕色标 (`accentColor`) |
| :--- | :--- | :--- | :--- | :--- | :--- |
| `narrator` | 旁白 | 温柔讲述者 | （不出画） | — | `rgba(255,255,255,0.35)` |
| `fox` | 小狐狸阿狸 | 好奇、善良的幼年赤狐 | 橘红色柔软毛发、奶油白色口鼻与胸口、深棕色四足脚尖、蓬松大尾巴带白色尾尖、敏锐大耳朵、小黑鼻，眼睛清澈自然有神；四足动物结构，不穿衣服、不戴围巾或饰品 | 禁止人类手掌、禁止直立穿衣、禁止多条尾巴、禁止巨眼卡通化 | `#FFC978` |
| `<role_id>` | `<名称>` | `<性格>` | `<发型/毛色/肤色 + 固定服装颜色与款式 + 标志性配件 + 体型比例>` | `<禁止变装/禁止多余肢体/禁止写实照片感>` | `<HEX色值>` |

### 核心道具与主场景锚点（Prop & Location Anchors）

若故事中有贯穿多个镜头的关键道具（如“星光种子”“旧怀表”“红色纸船”），同样必须锁定其**大小比例**与**材质特征**：
- **尺寸参照**：必须以角色身体部位作参照（例如：“约为小狐狸一只前爪长度的一半，可被双爪捧起，切勿画成篮球大小的发光球”）。
- **材质与光源**：明确发光颜色、透明度与表面机理（例如：“半透明自然椭圆种子外壳，内部封存蓝金色微光星点，光晕柔和不过曝”）。

## 2. 旁白与角色配音选角表（Voice Casting Guide）

当使用默认 `edge-tts`（或兼容微软音色的自部署服务）时，按角色性格选择差异化音色、语速（`speed`）与音调（`pitch`），避免全片所有角色听起来像同一个人：

| 角色类型 | 推荐 `edge-tts` 音色 ID | 建议语速 `speed` | 建议音调 `pitch` | 听感特点 |
| :--- | :--- | :--- | :--- | :--- |
| **温婉绘本旁白（默认旁白）** | `zh-CN-XiaoxiaoNeural` | `0.90 ~ 0.94` | `+0Hz` | 温暖、细腻、富有故事感染力 |
| **沉稳男声旁白 / 智者 / 树爷爷** | `zh-CN-YunjianNeural` 或 `zh-CN-YunyangNeural` | `0.88 ~ 0.92` | `-2Hz` | 厚重、慈祥、安定 |
| **机灵孩童 / 小动物主角（如小狐狸、小松鼠）** | `zh-CN-YunxiaNeural` | `0.95 ~ 1.02` | `+2Hz` | 少年感、清脆、灵动好奇 |
| **活泼少女 / 小鸟 / 精灵角色** | `zh-CN-XiaoyiNeural` | `0.96 ~ 1.04` | `+4Hz` | 清亮、轻盈、温柔 |
| **阳光青年 / 温和同伴** | `zh-CN-YunxiNeural` | `0.94 ~ 1.00` | `+0Hz` | 自然、干净、亲切 |

> **留白铁律**：
> - 每个镜头开场先留 `0.8s ~ 1.2s` 画面呼吸时间（`prePadSec`）再进第一句语音；
> - 同一镜头内旁白与角色对话之间留 `0.45s ~ 0.65s` 自然停顿（`lineGapSec`）；
> - 镜头最后一句语音结束后留 `0.9s ~ 1.5s` 余韵时间（`postPadSec`）再切下一镜。

## 3. 手绘水彩生图提示词拼接公式（Prompt Formula）

每个分镜的生图提示词（Prompt）必须由 **通用块 A（水彩画风 + 光色 + 出场角色锚点）** + **通用块 B（画幅与底部字幕留白）** + **镜头专属块 C（画面动作 + 景别构图 + 情绪 + 负面排除）** 组合而成。

### 通用块 A｜手绘水彩画风与角色锚点（每镜必带）

```text
【画风】柔和儿童绘本手绘水彩插画（hand-drawn storybook watercolor illustration），明显的冷压水彩纸纹理（cold-pressed watercolor paper texture），透明水彩叠色与自然水痕晕染（translucent watercolor washes, soft wet-on-wet pigment blooms），温暖细腻的彩铅/铅笔手绘轮廓线（gentle hand-drawn pencil and colored-pencil outlines）；角色主体轮廓清晰、边缘干净，远景与背景笔触更松弛概括、保留适度纸张留白；避免厚重油画感、避免 3D 塑料渲染感、避免摄影写实与过度锐化。
【光色】<填入当前镜头所属的色彩阶段，如：静谧深蓝绿秋夜底色，冷色月光环境光保留暗部水彩层次；唯一暖光源为琥珀金微光，光晕柔和不过曝>。
【出场角色】<原样粘贴本镜出场角色的固定外观描述块；若本镜为纯空镜或道具特写，写明“本镜无角色入画”>。
```

### 通用块 B｜画幅与字幕安全区（每镜必带）

```text
【输出规范】横向 16:9 完整单幅画面（或按用户指定的 9:16 竖屏），严禁出现任何文字、字母、汉字、签名、水印、印章、相框、白边或分镜多宫格拼图；画面底部约 12%～15% 区域保持柔和简洁（如草地、水面、路面或柔和暗部过渡），不放置角色脸部或关键道具，预留作绘本字幕安全区。
```

### 镜头专属块 C｜单镜构图与负面词模板

```text
【画面】<具体描述本镜内角色的姿态、动作、视线方向、与环境/道具的互动>。
【构图与景别】<明确远景/全景/中景/近景/微距特写>；<明确主体在画面中的位置，如“中景，镜头平视略低，主角位于画面左侧三分之一处朝右，视线落点在右侧树根处的微光，角色约占画面高度 1/3”>；<前景/背景层次说明>。
【情绪】<如：安静、好奇、屏息、温暖治愈、松一口气>。
【避免】<针对本镜容易画错的细节：如多余角色、多余肢体、角色被画幅边缘截断、夸张恐怖表情、文字水印、多格漫画框>。
```

## 4. 镜头语言与氛围动效设计表（Cinematography & FX Cue）

为了避免生成出来的视频像静态 PPT，分镜设计时必须满足：
1. **相邻两个镜头尽量切换景别**（例如：远景建立环境 → 中景角色动作 → 微距特写关键道具 → 中近景角色表情反应 → 全景情绪升华）。
2. **为每个镜头指定运镜方式（`cue`）与水彩氛围粒子（`fx`）**：

| 参数名 | 可选枚举值 | 视觉效果与适用场景 |
| :--- | :--- | :--- |
| **运镜 `cue`** | `push` | 镜头缓慢推进（`scale: 1.0 -> 1.07`），适合开场引入、聚焦细节、情绪递进 |
| | `pull` | 镜头缓慢拉远（`scale: 1.07 -> 1.0`），适合揭示全景、结尾收束余韵 |
| | `pan-right` / `pan-left` | 轻微横移摇镜（配合 `scale: 1.05` 防露边），适合旅途行进、跟随引路、环视环境 |
| | `grow` | 缓慢上移并微推，适合植物生长、希望升起、魔法绽放 |
| | `pulse` | 极轻微呼吸律动 + 暖光晕染起伏，适合特写凝视、发光物呼吸、梦境时刻 |
| | `still` | 稳定静帧（仅带极微弱纸面呼吸），适合短促对话或需要观众专注细微动作的镜头 |
| **色调 `tone`** | `night` / `cool` | 静谧蓝绿/月夜冷调（水彩冷色暗角与柔和月光） |
| | `glow` / `magic` | 蓝金/琥珀微光调（局部暖色呼吸光团叠加） |
| | `warm` / `dawn` | 温暖治愈橙金/晨光调（柔和暖金水彩晕染） |
| | `meadow` / `day` | 清新自然草木/晴日水彩调（通透明亮纸面感） |
| **氛围层 `fx`** | `leaves` | 缓慢飘落的秋叶/水彩叶片（适合森林、秋日、旅途） |
| | `starlight` | 呼吸闪烁的金色/蓝金星光微粒（适合魔法、夜晚、希望高潮） |
| | `petals` | 轻柔飞舞的花瓣/蒲公英（适合春日、苏醒、治愈重逢） |
| | `mist` | 缓慢流淌的薄雾与水痕柔光（适合清晨、湖畔、幽静山谷） |
| | `ripples` | 扩散的金色/水色涟漪光圈（适合水边、种子发芽、情绪共鸣） |
| | `none` | 仅保留水彩纸张肌理与柔和暗角（适合极简特写） |

## 全环节审计结论（2026-11-11）

**不存在必须补全才能继续的缺失素材**，可以继续渲染与迭代；当前无阻塞性视觉/运行时问题。

| 检查项 | 结果 |
|---|---|
| 61 帧全镜头批量渲染（54 轨中点帧 + 边界帧） | 61/61 成功，零运行时错误 |
| `scripts/tc_verify.py` 静态校验 | 54 段 MP3 时长与时刻表一致；波形口型 / 词级时间戳 54/54 完整；190 个零件引用、9 张背景、12 段环境人声、5 个音效全部落盘；帧连续性无重叠 |
| `npx tsc --noEmit` | 零错误 |

本轮修复的问题：

1. 短镜头（84 帧）撞上硬编码 `120` 使 `interpolate` 非单调而整页崩溃 → `lerp` 增加 `strictlyIncreasing` 防御，震动衰减改为按镜头时长自适应。
2. impact 镜头开场白闪与纸帘叠加过曝、短镜头末尾人物淡出成半透明 → Flash 峰值下调、纸帘在含 flash 的镜头静音、淡入淡出窗口缩短。
3. 咀嚼特写贴片被误读为「第二匹马」 → 新增 `badge` 圆形纸章，明确为特写插图。
4. 白马颈铃心形绳圈被抠白留洞 → 改用补充素材 `supp-bell-00` 独立铜铃。
5. 20 余个特写构图雷同 → 按角色分配背景（街市 / 马棚 / 饭馆前堂 / 黄昏）与镜头参数。
6. 背景自带夕阳与 `Sun` 特效重复叠加 → 移除重复项。
7. 跪地三帧过小 → 放大。
8. `.gitignore` 的 `*.wav` 使 5 个合成音效未纳入版本控制 → 增加 `!public/tiaocaoma/sfx/*.wav` 例外。

新增的长期校验 / 审计工具：`scripts/tc_verify.py`、`scripts/tc_audit.mjs`、`scripts/tc_audit_sheet.py`。

## 五、命名与规格约定

沿用现有素材命名，便于我直接替换：

```
01-背景/P<幕>-<序号>-BG-<名称>.png          1672×941，满幅不透明
02-角色/P<幕>-<序号>-CH-<名称>-剪纸拆件.png 1536×1024，纯白底、零件分散不接触
03-道具/P<幕>-<序号>-PR-<名称>.png          2172×724 或 1536×1024，纯白底
04-口型/P<幕>-<序号>-口型-<角色>.png        1774×887，4 列 × 2 行，每格 1 个口型
05-特效与标题/...                            纯白底或满幅
audio/音效-<名称>.wav                        22050Hz 以上，单声道即可
```

- 拆件图请保持**纯白背景 + 零件之间留白**，现有流水线会自动抠白、切分连通域、生成编号零件。
- 口型表请保持 **4 列 × 2 行**（0=闭、1=小、2=中、3=大），现有切分脚本按网格取最大连通块。
- **新增/替换素材时**：把图放进 `04-剪纸素材-补充`，在 `scripts/tc_assets.py` 的 `SUPP_FULL / SUPP_AUTO / SUPP_GRID` 登记，再重跑 `python scripts/tc_assets.py` → `python scripts/tc_timeline.py`（配音、波形口型与词级时间戳不变，无需重跑 `tc_audio.py` / `tc_edge_audio.py`）。

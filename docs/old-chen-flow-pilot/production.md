# 《老陈与八音盒 · 24fps 真动画三镜头打样》(OldChenFlowPilot)

## 1. 打样目标与双引擎架构说明

本作品是 `remotion-video-factory` 真动画引擎（`src/engine/`）的完整三镜头打样工程（Composition ID：`OldChenFlowPilot`，资源目录：`public/old-chen-flow-pilot/`，`1920x1080` @ `24fps`，总长 `20.71s` / `497 frames`）。

当前默认运行 **方案 B：纯本地 2D 骨骼级联 + 逐帧行走 + 自然眨眼 + 24fps 真实语音口型同步 (`mode: "layered-2d"`)**，无需依赖外部视频抽卡即可在本地 `100%` 确定性地呈现完整角色表演与精准中文对口型：

- **镜头 `01`（逐帧行走序列 + 门帘物理摆动）**：基于 `celSequence` 驱动 4 帧手绘水彩侧面行走/驻足序列帧（`visitor-walk-1~3.webp` + `visitor-stand.webp`），配合前景木门框棉麻门帘（`curtain.webp`）随推门动作自然掀起与回摆、吊灯暖光呼吸及微雨薄雾粒子。
- **镜头 `02`（父子骨骼级联 + 递盒动作 + 24fps 语音口型 + 自然眨眼）**：身体躯干（`visitor-body.webp`）→ 头部口型组（`visitor-head-closed/half/open.webp`，受 `VISITOR_LINE_ENVELOPE` 24fps 真实语音包络逐帧驱动）→ 眼部眨眼层（`visitor-eyes-open/closed.webp`）三级父子骨骼嵌套，同步驱动打开的胡桃木芭蕾八音盒（`music-box.webp`）轻推上台面与背景双挂钟钟摆（`pendulum-left/right.webp`）交错摆动。
- **镜头 `03`（180 度正反打 + 抬手扶镜关节 + 24fps 语音口型 + 自然眨眼）**：老陈躯干（`chen-body.webp`）挂载头部三态口型组（`chen-head-closed/half/open.webp`，受 `CHEN_LINE_ENVELOPE` 24fps 语音包络驱动）、镜片后自然眨眼层（`chen-eyes-open/closed.webp`）以及独立右臂肘关节（`chen-arm.webp`）抬手轻扶圆框眼镜，搭配绿罩银行台灯暖光、挂钟钟摆与星光微尘。
- *(可选扩展)*：仓库内同时保留了 `docs/old-chen-flow-pilot/flow-manifest.json` 与首尾关键帧 `shot-01~03-start/end.webp`，若后续切换 `mode: "auto"` 并放入 `video/shot-01~03.mp4` 亦可无缝对比 Google Flow 视频切片模式。

## 2. 180 度轴线与角色视觉锚点

- **小女孩（镜头 01、02）**：12 岁中国女生，黑色马尾与轻薄刘海，蓝白拼色运动校服外套；镜头 01 从左侧雨巷跨过门槛向右走至柜台前，镜头 02 位于画面左侧**面朝右**将打开的胡桃木芭蕾小人八音盒轻放在柜台上并抬头询问。
- **老陈（镜头 03 反打）**：60 多岁钟表收音机老匠人，两鬓斑白，圆框金属眼镜，耳后别黄色木铅笔，浅灰卷袖衬衣配深藏青围裙，身旁绿罩银行台灯与墙面机械挂钟；严格遵循 **180 度正反打轴线**，位于画面右侧**面朝左**抬头扶镜温和应允，与镜头 02 小女孩视线精准衔接。

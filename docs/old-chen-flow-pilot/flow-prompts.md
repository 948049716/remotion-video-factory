# 《OldChenFlowPilot》Google Flow 视频生成投喂手册

> **操作防坑提示（省积分必读）**：
> 1. 打开 [Google Flow](https://flow.google.com/) 新建项目后，输入框默认是图片模型，请先点击模型名切换为 **`Video -> Frames`**（或 `Ingredients`）。
> 2. 将生成条数 **`Outputs` 设为 `1`**，画幅设为 **`16:9`**，时长按每镜标注选择 `4s / 6s / 8s`。
> 3. 生成满意下载后，将视频命名为 `shot-01.mp4`、`shot-02.mp4` ... 放入 `assets/OldChenFlowPilot/flow-inbox/`（或上传至 Google Drive / 聊天窗口由 Agent 自动拉取质检）。

---

## 3. 分镜提示词

### 3.1 通用块（每次都复制）

**通用块 A｜画风与角色**

```text
请参考我上传的已确认风格图，生成一张二维分层动画用的分镜画面，保持同一只狐狸的造型与同一套画风。

【画风】柔和绘本水彩质感，轻微纸张纹理，平涂色块加水痕；角色轮廓清晰、边缘干净，背景更松弛、更概括；避免厚重油画笔触、过度锐化和高频碎纹理。
【光色】整体为低饱和深蓝绿秋夜，冷色环境光保留细节；画面中唯一暖光源是发光种子或星光小树，光晕柔和、范围合理、不过曝。
【主角】小狐狸阿狸，橘红色毛发、奶油白色口鼻与胸口、深棕色脚尖、白色蓬松尾尖、大耳朵、小黑鼻，眼睛自然有神、不夸张巨眼；不穿衣服、不戴配饰；脚爪保持狐狸爪，不要人类手掌。
【避免】多只狐狸、多条尾巴、多余肢体、畸形脚爪、角色或尾巴被裁切；衣服围巾背包饰品；其他额外主要角色；文字、水印、边框、分镜格、拼图、角色设定表；摄影写实、3D 塑料质感、恐怖森林、强烈霓虹。
```

**通用块 B｜输出**

```text
【输出】横向 16:9 完整画面，无文字、无字幕、无水印、无边框；画面底部约 12% 区域保持安静简洁，不放关键信息，留作字幕空间。
```

### 3.2 镜头 01｜秋夜森林远景推进

```text
【画面】秋夜的幽暗森林，薄雾与柔和月光；地面铺满赭色落叶与松针；小狐狸阿狸在画面中景偏左的落叶间低头嗅闻，正在寻找掉落的野山栗。身体四足站姿，完整入画，朝右。
【构图】比全景略近的中远景，能读出森林纵深与狐狸的体型关系；狐狸不要太小，约画面高度的 1/5～1/4；前景少量虚化草叶增加纵深，不能遮挡狐狸；远景以树影与雾气表现层次。
【情绪】安静、微凉、有一点孤单，但不是恐怖；狐狸神情专注好奇。
```

### 3.3 镜头 02｜树根微光

```text
【画面】千年古橡树盘根错节的树根之间，厚厚的枯叶层里透出一线柔和的蓝金色光，光只照亮附近一小片落叶与泥土；小狐狸从画面左侧探近，只有鼻尖、胡须、一只耳朵和一只前爪进入画面左下角，身体留在画外，正在嗅闻这团光。
【构图】中近景，树根占据画面右侧与下方主体，光源位于树根凹陷处；狐狸只做部分入画，强调“他发现了一点不寻常的光”。
【情绪】好奇、屏息，紧张度极低。
```

### 3.4 镜头 03｜好奇靠近（已确认图变体，可选重绘）

> 已确认风格图本身就是这一镜的构图，可直接作为分镜；若要统一运镜，可按下面重绘一版。

```text
【画面】小狐狸四足站姿，身体在画面左侧至中部、朝右；头部轻轻低下看向树根旁的发光种子；一只前爪微微向前探出但接近地面；耳朵微竖，嘴巴闭合，表情是克制的惊讶与好奇；蓬松大尾巴向左后方舒展，不遮脸、不遮种子。
【构图】中景，镜头接近狐狸视线高度；古橡树干在右侧，种子在中部偏右作为视线落点；狐狸、种子、古树根形成清晰三角关系。
```

### 3.5 镜头 04｜种子微距特写

```text
【画面】极近距离看这颗种子：小巧、闭合、略不对称的自然椭圆；外壳半透明，内部封存一小团缓慢旋转的星云，金色星点与淡蓝色外缘；光一明一暗，像在呼吸。种子躺在松软的泥土与落叶之间，周围地面被它映出柔和的暖光。
【构图】微距特写，种子占画面高度约 1/4～1/3，居中略偏右；背景完全虚化为深蓝绿色；不要出现狐狸，或只在边缘留一点橘色虚影。
【要求】必须仍能认出是种子，不是宝石、水晶、灯泡或悬浮魔法球；不要裂开的外壳，不要碗状结构。
```

### 3.6 镜头 06｜夜莺落肩

```text
【画面】小狐狸四足站姿、身体略侧，一只小小的夜莺刚刚落在他的右肩上，翅膀还微微张开；狐狸侧头看向肩上的鸟，眼神温和、有一点意外；他胸前靠近肩膀处，用一只前爪轻轻托着那颗发光的种子。
【构图】中景，狐狸完整入画，夜莺清晰可辨但不大于狐狸头部；背景为简化森林，前景极简。
【要求】夜莺小而真实：深色羽毛、浅色腹部，不拟人化、不放大眼睛；狐狸抬爪托物的动作要符合狐狸结构，不要出现人类手掌。
```

### 3.7 镜头 07｜作出决定

```text
【画面】小狐狸站在林间，身体朝右，头转向画面右侧的幽深森林（远处偏暗），胸前的种子发着光；他的前爪轻轻收拢护着种子，眼神从犹豫转为坚定，耳朵向前。
【构图】中景偏全景，画面右侧为较暗的森林纵深，左侧为狐狸；形成“看向远方、准备出发”的方向感；狐狸不要太小。
【情绪】安静但坚定，这是全片第一个转折点，不要演成害怕。
```

### 3.8 镜头 08｜月光引路

```text
【画面】森林高处的一段小径，夜莺在画面前方低飞引路，小狐狸跟在后面小跑或行走，四足自然、身体朝画面右前方；远处的林间空地透进柔和月光，小径旁可见一道浅浅的溪流反光。
【构图】中全景，用一条斜向的小径引导视线到远处的月光；狐狸在画面中段偏左下，夜莺在其前方；不要画成宏大风景照，狐狸仍需可辨。
【要求】这是过场镜头，环境和方向感比细节重要；不要出现荆棘缠斗、跳跃或打斗动作。
```

### 3.9 镜头 09｜轻轻种下

```text
【画面】俯视近景：松软的深色泥土里已经刨出一个深浅适中的小坑；小狐狸的两只前爪搭在坑边，其中一只正把发光的种子放进坑里，种子发出柔和的蓝金色光，照亮爪尖与坑壁。
【构图】俯视角，坑与种子位于画面中心偏下，两只前爪从画面上方伸入；不要出现狐狸全身。
【要求】泥土质感真实、松软、有少量落叶与草根；这是“郑重安放”的一刻，动作要轻，不要用力砸或抓。
```

### 3.10 镜头 11｜林地变暖

```text
【画面】月光林地的全景：那棵一人高的星光小树在画面中央偏右，它的暖光在地面铺开成一小片温暖区域，边缘的夜雾被推远、变薄；小狐狸坐在树旁偏左，身体放松，尾巴自然摊在地上；夜莺停在树的低枝上。
【构图】全景，镜头平视略高，留出较多天空与地面，强调“这片林地变了”；狐狸约占画面高度 1/6，仍能看清坐姿与尾巴。
【情绪】安定、温暖、松一口气；不要画成节日灯光或大规模光效爆发。
```

## 4. 素材与分层需求（草案）

拆分程度由动作决定，不追求“拆得越细越好”。

| 镜头 | 需要的图层 / 素材 | 备注 |
| --- | --- | --- |
| 01 | 远景森林（分层 2～3 层）、地面落叶、狐狸（站姿全身） | 镜头推进用图层位移＋缩放 |
| 02 | 古橡树根、枯叶层、光斑、狐狸局部（鼻/爪/耳） | 狐狸局部可用同一套部件裁切 |
| 03 | 已确认构图整体图；若做动画需：背景、狐狸身体、头部、尾巴、种子 | 头部与胸口毛发交叠处需补画 |
| 04 | 种子特写（外壳、内部星云各一层）、背景虚化 | 星云旋转用遮罩或缓速位移 |
| 05 | 狐狸坐姿（身体、头、双臂、尾巴）、苔藓层、花苞（闭/开两态）、种子 | 花苞用状态切换 |
| 06 | 狐狸站姿、夜莺（落肩/振翅两态）、种子、背景 | 夜莺用两帧循环 |
| 07 | 狐狸站姿（头转向）、种子、暗部森林背景 | 头部转向需独立头部图层 |
| 08 | 小径背景、溪流反光、夜莺飞行（2～3 帧）、狐狸奔跑/行走 | 可用循环位移代替逐帧 |
| 09 | 泥土俯视背景、小坑、两前爪（各一）、种子 | 爪部可复用 |
| 10 | 小树（树干、枝叶 2～3 层、星光粒子）、涟漪、狐狸站姿、夜莺 | 生长用遮罩＋缩放 |
| 11 | 林地全景（背景 2 层）、小树、暖光、狐狸坐姿、夜莺 | 暖光用渐变叠加而非重绘 |
| 12 | 狐狸蜷卧（身体、尾巴、闭眼头）、小树、夜莺、草地 | 尾巴盖鼻是关键剪影 |

**通用分层原则**

1. 先按“会不会动”决定拆不拆：只眨眼的镜头不必拆腿。
2. 关节处（颈、肩、尾根）留 2～4 px 重叠区，转动时不露缝。
3. 被遮挡的背景要补画，或设计成永不露出。
4. 光效（种子光、树光、涟漪）独立成层，用透明度与缩放做呼吸，不叠进角色贴图。
5. 同一角色的部件保持同一画布尺寸与同一锚点，便于复用。

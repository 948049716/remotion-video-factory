# 分镜提示词包 — 小狐狸找到发光种子

每个镜头是**一整段可复制**的独立提示词（已把通用画风块合入）。
生成时把**已确认的风格参考图**一并上传，作为角色与画风的基准。

- 尺寸：16:9，优先 1536×864 或原生 16:9
- 命名与回传：生成后按 `shot-01` … `shot-12` 命名（扩展名不限，png/jpg/webp 均可）
- 底部 12% 留空，后续放字幕
- 这 12 张是**分镜图**，不是可直接拆层的正式素材
